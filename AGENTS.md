# Autoslash AI - Project Memory

## Founder
Based in Dakar, Senegal. Visionary entrepreneur.

## Mission
Autoslash AI is an intelligent scalable infrastructure – not just a tool. It creates personalized AI web applications for clients in Senegal and worldwide. Each application includes AI agents trained on specific client data. Clients receive a complete solution and build nothing themselves.

## Technical Stack (Mandatory)
- **Frontend**: Next.js 15 + Tailwind CSS
- **Database**: Supabase (PostgreSQL + pgvector + RLS)
- **Authentication**: Clerk or Supabase Auth
- **Deployment**: Vercel + Railway
- **Versioning**: GitHub (autoslash-ai organization)
- **AI Agents**: Claude API + Gemini API + OpenAI fallback
- **Automation**: n8n (self-hosted on Railway)
